[FIX] Faraday `bulk_create` c-5.21.x compatibility across every executor that emits vulns. Two landmines fixed: (a) `refs[].type` must be one of `{exploit, patch, other}` — using `cve`/`url` caused silent HTTP 400 dropping the entire payload; standardized on `type: "other"` with CVE/URL identity carried in `refs[].name`; (b) hosts are keyed server-side by `ip`, so leaving every asset at `0.0.0.0` collapsed all logical assets into one Faraday host row — executors now promote the resolved hostname into the `ip` field when the source ip is a placeholder. Also backfilled `bulk_create` mandatory fields (`vuln.data`, `vuln.external_id`) so recent Faraday server versions accept the payload. #276
